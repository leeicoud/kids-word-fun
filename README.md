# ☀️ 小太阳萌趣背单词 (Kids Word Fun)

> 专为小学生设计的趣味单词记忆网页应用，萌趣卡通风格，支持在线同步开源教材词库，配有真人发音、乌龟慢读、听音闯关、字母拼拼乐与星星奖励机制！

---

## 🌟 核心特色与设计亮眼点

1. **🎨 糖果卡通主流审美设计**：
   - 暖阳与糖果配色，搭配圆润卡片、拟态阴影与萌趣动效。
   - 每个单词配套专属卡通 Emoji、趣味例句与神奇谐音记忆口诀。
2. **🔊 双语速标准发音与听读体系**：
   - **小乌龟慢读 🐢**：专为小学生设计的 0.65 倍语速精听模式，音节清晰明了。
   - **标准真人发音 🔊**：支持美式口音（🇺🇸）与英式口音（🇬🇧）一键切换。
   - **纯原生音效合成**：采用 Web Audio API 合成水滴啵啵声、答对大和弦与星星收集音效，免网络依赖。
3. **📚 在线公开词库与自由切换**：
   - **开源教材在线同步**：实时接入《小学 1-6 年级英语单词系统分类》（576 词全量版）、人教版 PEP 英语（三年级至六年级）、剑桥少儿英语等公开词库。
   - **大纲 28 大系统分类**：颜色、学校、文具、数字、家庭、身体、家居、衣物、时间、星期、月份、季节、人物、形状、食物、自然、地点、其他名词、形容词、副词、天气、动词、方位介词、代词、动物、交通、动词短语、名词短语。
   - **萌趣主题精选库**：动物园、美味水果、校园生活、自然天气等。
   - **自定义在线词库导入**：支持输入任意网络公开 JSON 词库链接一键学习。
4. **🎮 三大多维学习模式**：
   - **📖 3D 卡通识词卡**：自由翻牌、上一词/下一词、随机乱序、自动轮播朗读。
   - **🎯 听音闯关大挑战**：听音选词四选一，连击 Combo 炸裂彩带纸屑。
   - **🧩 字母拼拼乐**：糖果字母气球拼词，强化拼读与字母认知。
5. **⭐ 学情记录与激励打卡**：
   - 收集奖励小星星、掌握单词本、生词收藏，数据本地持久化。

## ☁️ 免费部署指南（零服务器成本）

本项目为标准的纯静态应用（SPA），构建产物位于 `dist/` 目录，无需任何后端服务器，可永久免费部署在以下平台：

### 1. Vercel（推荐，10秒自动化上线）
1. 注册/登录 [Vercel](https://vercel.com)；
2. 关联你的 GitHub 仓库，选择本项目；
3. 点击 **Deploy**，平台自动识别 Vite 并生成全球加速访问域名（如 `https://kids-word-fun.vercel.app`）。

### 2. GitHub Pages（全自动 Actions 部署）
项目已内置 `.github/workflows/deploy.yml` 自动化工作流：
1. 将代码 push 到 GitHub 仓库；
2. 在仓库的 **Settings -> Pages -> Build and deployment -> Source** 中选择 **GitHub Actions**；
3. 以后每次推送代码都会自动打包并上线到 `https://<你的用户名>.github.io/<仓库名>/`。

### 3. Cloudflare Pages / Netlify
- **构建命令**：`npm run build`
- **构建输出目录**：`dist`
- 永久免费无限流量，国内访问速度极快。
